# LocalSend Web

ส่งไฟล์ ลิงก์ และข้อความ ระหว่างอุปกรณ์ที่เปิดเว็บนี้อยู่ — เหมือน LocalSend แต่ใช้ผ่านเบราว์เซอร์ ไม่ต้องติดตั้งแอป

- ไฟล์วิ่ง **ตรงระหว่างอุปกรณ์** ด้วย WebRTC (เข้ารหัส) ไม่อัปโหลดขึ้นเซิร์ฟเวอร์
- อุปกรณ์ที่ใช้ **Wi‑Fi เดียวกัน** จะเห็นกันอัตโนมัติ
- อยู่คนละเครือข่ายก็ได้ — กดปุ่ม **ห้อง** แล้วสแกน QR / ใส่รหัสห้อง
- ผู้รับต้องกด **รับ** ก่อนทุกครั้ง (เปิด "รับอัตโนมัติ" ได้ในตั้งค่า)
- ลากไฟล์มาวาง, Ctrl/⌘+V วางรูป/ข้อความ, ดูตัวอย่างรูป, คัดลอกข้อความ, เปิดลิงก์, แสดงความเร็วและเวลาที่เหลือ

## Deploy ขึ้น Vercel

ไม่ต้อง build อะไร เป็นเว็บ static + ฟังก์ชันเล็ก ๆ 1 ตัว (`api/room.js`)

**วิธีที่ 1 — ผ่าน GitHub (แนะนำ)**
1. อัปโหลดทั้งโฟลเดอร์นี้ขึ้น GitHub repo ใหม่
2. ไปที่ vercel.com → **Add New… → Project** → เลือก repo
3. Framework Preset: **Other** · Build Command: เว้นว่าง · Output Directory: เว้นว่าง → **Deploy**

**วิธีที่ 2 — ผ่าน CLI**
```bash
npm i -g vercel
cd localsend-web
vercel --prod
```

## โครงสร้าง

```
index.html            หน้าเว็บ
style.css             สไตล์ (รองรับโหมดมืด/มือถือ)
app.js                ตรรกะทั้งหมด: ค้นหาอุปกรณ์, ส่ง/รับ, UI
api/room.js           Vercel Function: แปลง IP สาธารณะ → รหัสห้อง (hash, ไม่เก็บ IP)
vendor/peerjs.min.js  PeerJS 1.5.4 (WebRTC)
vendor/qrcode.js      สร้าง QR code
vercel.json           security headers
```

## ทำงานอย่างไร

1. แต่ละแท็บเป็น peer ของ PeerJS (ใช้ signaling server ฟรีของ PeerJS แค่ตอนจับคู่)
2. รหัสห้องมาจาก `/api/room` (อุปกรณ์หลัง router เดียวกัน = IP สาธารณะเดียวกัน = ห้องเดียวกัน) หรือจาก `?room=CODE`
3. อุปกรณ์แรกในห้องเป็น "hub" คอยแจกรายชื่ออุปกรณ์ ถ้าออกไป อุปกรณ์อื่นรับช่วงต่ออัตโนมัติ
4. ตอนส่ง จะเปิดช่อง WebRTC ตรงไปยังเครื่องปลายทาง ส่งคำขอ → ผู้รับกดรับ → ไฟล์ถูกแบ่งเป็นชิ้นส่งไป

## ข้อจำกัดที่ควรรู้

- **โหมดอัตโนมัติอิง IP สาธารณะ** ถ้าใช้เน็ตมือถือ (4G/5G) หรือเครือข่ายใหญ่ที่แชร์ IP อาจเห็นอุปกรณ์ของคนอื่นด้วย — ใช้ "สร้างห้องส่วนตัวใหม่" เมื่อต้องการความเป็นส่วนตัว (และผู้รับต้องกดยืนยันเสมอ)
- ถ้าบางเครื่องออกเน็ตด้วย IPv6 และอีกเครื่องด้วย IPv4 อาจไม่เห็นกันอัตโนมัติ → ใช้ QR/รหัสห้อง
- ต้องเปิดหน้าเว็บค้างไว้ทั้งสองฝั่งระหว่างส่ง (มือถือที่ปิดจอ/สลับแอป อาจตัดการเชื่อมต่อ)
- ไฟล์ที่รับจะพักในหน่วยความจำก่อนกดบันทึก ไฟล์ใหญ่มาก (หลาย GB) อาจไม่ไหวบนมือถือ
- บางเครือข่ายที่บล็อก WebRTC แบบตรง จะใช้ TURN ฟรีของ PeerJS ซึ่งช้ากว่า

## ใช้ PeerServer ของตัวเอง (ไม่บังคับ)

ใส่ก่อนบรรทัด `<script src="app.js">` ใน `index.html`:
```html
<script>window.LSW_PEER_OPTS = { host: 'your-peer-server.example.com', port: 443, path: '/', secure: true };</script>
```
